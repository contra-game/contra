# Contra City — прототип на Godot 4

Сетевой шутер в духе «Контра Сити»: городской квартал, хитскан-стрельба с
разбросом и отдачей, боты, подбор оружия. Играбельный прототип, на котором
дальше наращивается контент.

Открыть: запустить `Godot_v4.7.2-stable_win64.exe`, добавить эту папку как
проект, нажать F5. Движок — Godot 4.4+, скрипты на GDScript, C# не нужен.

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD | движение |
| Shift | бег |
| Ctrl | присед (меньше разброс, ниже силуэт) |
| Space | прыжок |
| ЛКМ | огонь |
| ПКМ | прицеливание (уже разброс, медленнее ход) |
| R | перезарядка |
| 1 / 2 / колесо | смена оружия |
| E | подобрать ствол с точки |
| Esc | пауза |

## Что уже работает

- **Стрельба.** Хитскан по лучу из центра экрана, разброс зависит от движения,
  прыжка, приседа и прицеливания; каждый выстрел добавляет разброс и отдачу,
  которые восстанавливаются со временем. Прицел на экране расходится ровно на
  текущий угол разброса — куда он показывает, туда и уйдёт пуля.
- **Шесть стволов.** AK-47, M4A1, SPAS-12 (9 дробин за выстрел), AWP (болтовка
  с оптикой), Deagle, Glock-18. У каждого свои урон, падение урона по
  дистанции, бронепробитие, отдача, скорость хода.
- **Урон.** Хедшоты (множитель у каждого ствола свой), броня, поглощающая часть
  урона, падение урона на дистанции.
- **Боты.** Патрулируют, замечают цель в поле зрения с проверкой линии огня,
  стрейфятся в бою, держат дистанцию, стреляют очередями с задержкой реакции,
  перезаряжаются, разворачиваются на выстрел в спину.
- **Карта.** Городской квартал 85×85 м из CC0-моделей Kenney: дома,
  небоскрёбы, заводы, перекрёстки с разметкой, контейнеры-укрытия,
  водонапорные башни. Собирается кодом по текстовой схеме.
- **Интерфейс.** Здоровье, броня, патроны, киллфид, счёт, хитмаркер (отдельный
  цвет для хедшота и для убийства), вспышка при получении урона, пауза.
- **Звук.** Записанные выстрелы (CC0), остальное синтезируется кодом.

## Структура

```
scenes/    main, player, bot — сцены, которые правятся в редакторе
scripts/   вся логика
  game.gd            матч: спавны, счёт, респавны, киллфид
  map_builder.gd     сборка карты по схеме LAYOUT
  player.gd          движение, камера, присед, отдача
  weapon_manager.gd  инвентарь, стрельба, перезарядка, вид оружия
  weapons_db.gd      каталог стволов (autoload Weapons)
  weapon_data.gd     описание одного ствола
  bot.gd             ИИ противника
  health.gd          здоровье и броня
  damage.gd          единая точка нанесения урона
  effects.gd         трассеры, попадания, дульная вспышка
  sfx.gd             звук (autoload Sfx)
  hud.gd, crosshair.gd  интерфейс
tools/     smoke_test и screenshot — проверки без редактора
assets/    модели города и звуки оружия
```

## Как править

- **Карта** — константа `LAYOUT` в `scripts/map_builder.gd`. Один символ равен
  клетке 6.5 м: `#` дом, `I` завод, `x` контейнер, `t` водонапорка,
  `P` спавн игрока, `B` спавн бота, `w` точка оружия, `.` пусто.
- **Баланс оружия** — `scripts/weapons_db.gd`, по словарю на ствол. Новый ствол
  = ещё один вызов `_register(_make({...}))`.
- **Сложность ботов** — экспорты в `scripts/bot.gd`: `reaction_time`,
  `accuracy_penalty`, `sight_range`. Количество — `bot_count` в `game.gd`.

## Проверки без редактора

```bash
Godot_v4.7.2-stable_win64.exe --headless --path . res://tools/smoke_test.tscn
```

Поднимает матч на 6 секунд и печатает состояние: объекты карты, позицию и
оружие игрока, сколько ботов живо и в бою, проходит ли урон. Скриншоты —
`res://tools/screenshot.tscn` (без `--headless`).

## Чего ещё нет

- **Сеть.** Код уже разделён на серверную логику (урон, спавны, ИИ — всё за
  проверками `multiplayer.is_server()`) и клиентскую (HUD, эффекты). Чтобы
  включить игру по сети, нужно поднять `ENetMultiplayerPeer`, повесить
  `MultiplayerSpawner` на узел `Actors` и `MultiplayerSynchronizer` на игрока.
- Моделей игрока и оружия от третьего лица нет: тело — капсула, вид оружия от
  первого лица собран из примитивов по длине ствола.
- Нет покупки оружия, режимов матча, карт кроме одной, гранат и ножа.

## Лицензии ассетов

- Модели города — [Kenney](https://kenney.nl), CC0: [City Kit
  Commercial](https://kenney.nl/assets/city-kit-commercial), [City Kit
  Industrial](https://kenney.nl/assets/city-kit-industrial), [City Kit
  Roads](https://kenney.nl/assets/city-kit-roads).
- Звуки выстрелов — [The Free Firearm Sound
  Library](https://opengameart.org/content/the-free-firearm-sound-library), CC0.

CC0 — можно использовать как угодно, в том числе коммерчески, без указания
авторства. Исходники загрузок лежат в `assets/downloads` и `assets/raw`
(≈300 МБ) и в игре не нужны — их можно удалить.
